# Contributing

This repository is still in an early drafting stage.

If you contribute to UPP:

- keep changes scoped to concrete procurement workflows
- prefer changes backed by examples, schemas, or implementation needs
- avoid broadening the protocol without a clear interoperability case
- keep language technical and precise
- document breaking changes to schemas or APIs clearly

Before proposing public changes:

- review the draft specification in `docs/upp-draft-spec.md`
- validate related examples and schemas
- keep extensions namespaced and explicit
